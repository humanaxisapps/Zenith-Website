When we started designing Zenith, the easy path was to add more: more charts, more settings, more ways to configure every limit down to the minute.

We went the other way instead.

## Fewer screens, clearer choices

Every extra screen is a decision the user has to make before they even get to the thing they came for. So we asked a simple question for every feature:

*Does this help someone put their phone down, or does it just give them something new to look at?*

If the answer wasn't a clear yes, it didn't make the cut.

## Designing for the moment of temptation

The hardest moment isn't setting a limit, it's the moment right before you're about to break it. That's the one screen we obsessed over more than any other.

```
if (isAboutToOverride) {
  showOneCalmQuestion();
}
```

No shame, no guilt trips, just one calm pause before the decision is made.

## What's next

We're continuing to strip things back rather than add them. If a future update makes Zenith feel busier instead of calmer, we've gotten something wrong.

Thanks for reading, and thanks for using Zenith.
