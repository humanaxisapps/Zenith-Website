---
title: "Limits UX uplift"
---

![Zenith app blocker and app limits for iPhones and iPads](/app_view/release_notes/2026-07-05.png)

The first version of Zenith displayed limits in a 2x2 grid. Some users told us it wasn’t immediately clear what type of limit each one represented.

Based on this feedback, we updated the layout to a single-column list with more context around each limit, making it easier to understand the different limit types at a glance.
